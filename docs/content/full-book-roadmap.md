# 数学分析整本内容路线图

日期：2026-06-03

## 目标

把《数学分析》上下册整理成可在学习工作台中使用的结构化课程内容：

- 每章有 `chapters/<chapter>.json`。
- 每章有 `exercises/<chapter>.json`。
- 需要图示的章节有 `diagrams/<chapter>.json`。
- 每章至少覆盖核心知识点、证明思路、苏格拉底追问、常见误区、掌握标准和分层练习。

## 内容原则

- 不提交 PDF。
- 不复制教材正文和大段原题原文。
- 讲义、解释、提示、评分要点使用自编表达。
- 题源可记录教材章/节/题号；题面优先做原创或充分改写。
- 无法核对题号时写清“待核对题源”，不得编造题号。

## 每章完成标准

每章从 `planned` 升到 `draft` 的最低标准：

- 至少 6 个知识点。
- 至少 8 道练习题。
- 每个知识点字段完整。
- 每道题有 difficulty/type/recommendedTiming/gradingRubric/hints/commonMistakes。
- 章节文件和题目文件能通过 JSON 解析。
- 无 unresolved placeholder 词。

每章从 `draft` 升到 `sample-ready` 的标准：

- 覆盖该章主要定义、定理、证明方法和典型题型。
- 每个知识点至少关联 1 道练习。
- 关键证明类知识点有 proofIdeas。
- 需要图示的知识点有 diagramIds 或明确说明不需要图。
- 题源核对记录写入对应 review 文档。

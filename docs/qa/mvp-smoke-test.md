# MVP 手动冒烟测试清单

日期：2026-06-02
对应任务包：9（QA 验收清单与风险列表）

本清单供任何人（不必懂代码）在每次改动后按步骤检查学习工作台的关键流程是否正常。每条都写了**操作步骤**和**预期结果**；只要有一条不符，就记为失败并在表末记录。

## 准备

1. 启动开发服务器（开发者已运行时可跳过）：`npm run dev`。
2. 浏览器打开 `http://localhost:3000`。
3. 准备一张手机拍的手写解答照片（任意，<8MB），用于图片上传测试。

> 说明：AI 批改需要有效的模型 API Key。没有 Key 时，第 9–14 项设置类检查仍可完成；真正的“提交给 AI 批改”会提示需要先填 Key（这是预期行为，见第 15 项）。

---

## 冒烟检查项

### 1. 首页能打开
- 操作：访问 `http://localhost:3000`。
- 预期：页面正常加载，出现三栏式学习工作台（左：目录；中：讲义/题目；右：AI 老师），无整页报错或白屏。

### 2. 左侧目录显示章节
- 操作：查看左侧栏。
- 预期：显示《数学分析》上册章节列表，能看到“数列极限”章及其小节；点击小节会切换中间内容。

### 3. 公式用 KaTeX 渲染，不显示裸 `$x_n$`
- 操作：进入“数列极限”任一知识点，查看讲义和题目中的公式。
- 预期：公式以排版形式显示（如 ε、分式、下标），**不出现**原始的 `$...$` 美元符号或 `\varepsilon` 这类未渲染源码。

### 4. 教学图示非空
- 操作：进入含图示的知识点（如 epsilon-N 定义）。
- 预期：能看到数轴/数列点等教学图示被画出来，不是空白占位框。

### 5. 练习题可切换
- 操作：在练习区点击不同难度标签（basic/medium/hard 标签按钮）。
- 预期：题面随之切换；切换后答案输入、提示、批改结果被清空（重置为新题状态）。

### 6. 提示按钮按层级显示
- 操作：在某题反复点击“获取提示”。
- 预期：每点一次多显示一条提示，由浅入深；到达该题最后一条提示后不再增加（不会越界）。

### 7. 文本答案可输入
- 操作：在“输入你的解答”文本框输入一段文字/公式。
- 预期：文本正常显示在输入框中，可编辑。

### 8. 图片答案可上传、预览、移除
- 操作：点击“拍照/上传答案”，选择 1–2 张图片；然后点其中一张的“移除”。
- 预期：上传后出现缩略图预览（带文件名）；点“移除”后该图消失，其余保留。

### 9. AI 老师设置能选择 DeepSeek 和 Xiaomi MiMo
- 操作：右侧“AI 老师”区，打开“模型供应商”下拉框。
- 预期：下拉项至少包含 OpenAI-compatible、DeepSeek、Xiaomi MiMo、Gemini；选择 DeepSeek 或 Xiaomi MiMo 后，模型名与 Base URL 会自动填入该供应商的预设值。

### 10. Base URL 输入框存在
- 操作：查看设置区。
- 预期：有一个标注“Base URL”的输入框（占位提示 “OpenAI-compatible Base URL”），可手动编辑。

### 11. API Key 不显示明文
- 操作：在 “API Key” 输入框输入任意字符。
- 预期：输入内容显示为圆点/星号（密码框），不显示明文；占位提示为“API Key 仅保存在浏览器本地”。

### 12. 模型名可编辑
- 操作：在“模型名称”输入框修改模型名。
- 预期：可自由输入；切换供应商时会被重置为该供应商默认模型。

### 13. 保存设置
- 操作：填好供应商/模型/Base URL/API Key 后点“保存设置”。
- 预期：无报错；设置被写入浏览器本地存储（键名 `ai-math-tutor-settings`）。

### 14. 页面刷新后模型设置能从 localStorage 恢复
- 操作：保存设置后刷新页面（F5），再查看设置区。
- 预期：供应商、模型、Base URL 恢复为刷新前的值（API Key 也会恢复，因为本地保存）。

### 15. 未填 Key 时批改有明确提示
- 操作：清空 API Key，写一段答案后点“提交给 AI 批改”。
- 预期：出现提示“请先在右侧 AI 老师区域保存模型和 API Key。”，不会静默失败。

### 16. 填好 Key 后能得到 AI 批改结果（需有效 Key）
- 操作：填入有效 Key，写一段答案，点“提交给 AI 批改”。
- 预期：按钮变“批改中...”，随后出现“AI 批改结果”卡片，含分数、反馈，必要时列出“还缺这些要点”；左上“当前掌握状态”徽标随之更新。

### 17. 掌握状态徽标随批改更新
- 操作：完成一次批改后查看练习区右上的“当前掌握状态”。
- 预期：显示 未学/初步掌握/熟练/薄弱 之一，且与本次批改结果一致；刷新页面后该状态仍保留（本地持久化）。

### 18. 图片答案能随文本提交给视觉模型（需支持视觉的有效 Key）
- 操作：上传一张手写答案图片（可不填文本），点“提交给 AI 批改”。
- 预期：能得到批改结果；若模型看不清，反馈中会说明不确定处，而不是假装识别准确。

# 数列极限教学图示说明

本文件说明“数列极限”样板章节的 6 张程序化图示如何用于教学。图示规格位于：

```text
content/courses/math-analysis/diagrams/sequence-limit.json
```

这些图示应由前端用 SVG 或 Canvas 根据参数渲染。AI 可以解释图示，但不直接生成或改写图示，以保证数学关系可控。

## 1. 数轴上的 epsilon 邻域

图示 ID：

```text
epsilon-neighborhood-on-number-line
```

用途：

- 用数轴解释 $|x_n-a|<\varepsilon$。
- 把绝对值不等式翻译成开区间 $(a-\varepsilon,a+\varepsilon)$。
- 让学生理解 epsilon 是任意精度，不是固定小量。

建议讲法：

先展示极限点 $a$，再展示左右两侧距离 $\varepsilon$ 的端点。让学生指出哪些点满足 $|x_n-a|<\varepsilon$，再把图和定义中的“任给 $\varepsilon>0$”连接起来。

## 2. 从某项之后全部落入邻域

图示 ID：

```text
sequence-eventually-inside-neighborhood
```

用途：

- 解释“存在 $N$，当 $n>N$ 时”的含义。
- 区分早期有限项和足够大以后的尾部行为。
- 说明极限定义允许有限多个项在邻域外。

建议讲法：

先让学生观察前几项可能在邻域外，再标出阈值 $N$。重点强调不是“所有项都在邻域内”，而是“从某一项以后所有项都在邻域内”。

## 3. 收敛与不收敛数列对比

图示 ID：

```text
convergent-vs-divergent-sequence
```

用途：

- 对比 $x_n=1/n$ 与 $x_n=(-1)^n$。
- 说明“有规律”不等于“有极限”。
- 引导学生用 epsilon 邻域语言判断收敛。

建议讲法：

先让学生凭图判断两个数列是否有单一趋近目标，再要求学生用定义解释。右图可追问：若假设极限为 0，取小于 1 的 epsilon 时，为什么无法满足定义？

## 4. 收敛数列必有界

图示 ID：

```text
bounded-sequence
```

用途：

- 展示收敛性如何控制尾部。
- 说明前面有限项需要单独取最大界。
- 支撑“收敛数列必有界”的证明。

建议讲法：

先用收敛定义取 $\varepsilon=1$，得到尾部落在 $(a-1,a+1)$ 中。再指出前面有限项可能跑得很远，所以要把有限前缀的绝对值最大值和 $|a|+1$ 一起取最大。

## 5. 单调有界数列趋近极限

图示 ID：

```text
monotone-bounded-convergence
```

用途：

- 展示单调递增有上界的数列如何逼近上确界。
- 解释极限候选值为何是 $s=\sup\{x_n\}$。
- 支撑单调有界收敛定理的证明思路。

建议讲法：

先区分“上界”和“上确界”：上界可以很多，上确界是最小上界。证明中要用 $s-\varepsilon$ 不是上界，所以存在某项 $x_N>s-\varepsilon$，再由单调性推出所有后续项都在 $(s-\varepsilon,s]$ 内。

## 6. 子列与原数列的收敛关系

图示 ID：

```text
subsequence-idea
```

用途：

- 解释子列是在保持原顺序的前提下抽取无限多项。
- 展示收敛数列的任意子列仍收敛到同一极限。
- 用 $(-1)^n$ 的奇数项和偶数项子列说明发散判定。

建议讲法：

先高亮奇数项子列和偶数项子列。奇数项恒为 $-1$，偶数项恒为 $1$，两个子列极限不同，因此原数列不可能有唯一极限。

## 前端实现提示

- 图示应作为课程内容的一部分，而不是装饰背景。
- 图示组件接收 JSON 参数并渲染，避免把数学关系硬编码在页面文案中。
- 每张图旁边应显示一个短问题，让学生必须读图并回答。
- 图示可以与 AI 追问联动，但 AI 的上下文应只包含当前图示 ID、参数、teacherNotes 和 studentPrompt。
- 数学公式统一交给 MathJax 或 KaTeX 渲染。

# 学习工作台信息架构草案（第一版）

日期：2026-06-02
对应任务包：E（UI 信息架构草案）
依据：设计文档第 3、4、9 节；内容 schema 见 `content/courses/math-analysis/README.md`；AI 任务见 `docs/ai/tutor-prompt-spec.md`

本文件定义第一版「学习工作台」的页面清单、布局结构、组件边界与视觉原则，供前端搭建直接参照。第一版以电脑和平板体验为主，移动端保证基本可用。

---

## 1. 设计目标与边界

- 首页不是营销页，进入即学习工作台（设计文档第 3 节）。
- 体验应像「跟着老师同步学习课本」：选课 → 进目录 → 进样板章 → 按知识点走闭环 → 记录掌握度。
- 第一版只有《数学分析》一门课、上册目录、「数列极限」样板章为可学。其余章节在目录中显示状态占位（`planned`），点击给出「尚未开放」提示。
- AI 始终绑定「当前知识点 / 当前题目」，UI 不提供脱离课程脚本的自由聊天入口。

---

## 2. 页面清单

| # | 页面 | 路由建议 | 职责 |
| --- | --- | --- | --- |
| P1 | 课程首页 | `/` | 展示课程卡片，进入《数学分析》；显示整体学习进度入口 |
| P2 | 章节学习页 | `/course/[courseId]` | 上册目录树 + 章节状态 + 选择进入某章/小节 |
| P3 | 当前知识点学习区 | `/course/[courseId]/kp/[knowledgePointId]` | 学习闭环主舞台：讲义、定义、定理、图示、例题 |
| P4 | AI 老师互动区 | P3 内的右栏 / 移动端抽屉 | 承载 explain/ask 对话与追问 |
| P5 | 练习与批改区 | P3 内的中栏题目卡 + 右栏反馈 | 承载题目作答、hint、grade、反馈 |
| P6 | 模型/API Key 设置页 | `/settings` | 选择模型供应商与模型，填写并本地保存 API Key |
| P7 | 学习进度与掌握状态 | `/progress`（也可作 P2 侧栏） | 各知识点掌握度概览 |

> P3、P4、P5 在桌面端是**同一屏的三个区域**，不是三个独立页面；分列只为说明职责边界。

## 3. 桌面 / 平板布局（主形态）

三栏工作台（设计文档第 3 节）：

```text
+----------------------------------------------------------------------+
| 顶栏: 课程名 | 面包屑(章 > 小节 > 知识点) | 设置入口 | 进度入口        |
+----------------+-----------------------------------+-----------------+
|  左栏 (P2)     |  中栏 (P3 + P5)                    |  右栏 (P4 + P5)  |
|  课程目录/进度  |  讲义 / 公式 / 图示 / 例题 / 题目   |  AI 老师 / 提示  |
|                |                                   |  / 批改反馈      |
|  - 章列表       |  [当前教学步骤指示器]              |                 |
|  - 小节         |  [讲义区 coreExplanation+定义定理] |  [对话流]        |
|  - 知识点+状态  |  [图示区 diagram]                 |  [提示分层]      |
|  - 掌握度标记   |  [例题/题目卡 + 作答框]           |  [批改结果卡]    |
+----------------+-----------------------------------+-----------------+
```

- **左栏**：课程目录与进度。章/小节/知识点三级，每个知识点旁显示掌握度徽标（见 §6）。点击切换中栏内容。
- **中栏**：当前知识点的讲义、公式、图示、例题与练习题。顶部有「教学步骤指示器」标出当前处于闭环第几步。
- **右栏**：AI 老师互动与反馈。对话流 + 提示分层控件 + 批改结果卡。

平板（≥768px 且 <1024px）：右栏可折叠为可拉出的侧抽屉，中栏占主区；左栏变为顶部下拉的目录按钮。

## 4. 移动端简化布局

```text
+-------------------------------+
| 顶部: 课程位置(章>小节>知识点) |   <- 紧凑面包屑 + 进度条
+-------------------------------+
|                               |
|   主体: 当前学习步骤           |   <- 单步聚焦：讲义 / 图示 / 题目
|   (一次只显示闭环中的一步)     |      之一，随步骤切换
|                               |
+-------------------------------+
| 底部: [上一步][步骤][下一步]   |   <- 步骤导航
| [AI 辅导] 抽屉/标签页          |   <- 点击拉起 AI 老师 (P4/P5)
+-------------------------------+
```

- 顶部：课程位置 + 该知识点进度。
- 主体：当前学习步骤单步聚焦，避免三栏拥挤。
- 底部：步骤导航 + 「AI 辅导」抽屉（或底部标签页）承载 explain/ask/hint/grade。

## 5. 组件边界

按职责拆分，便于前端独立实现与复用。括号内为关联的数据字段 / AI 任务。

### 5.1 导航与框架
- `AppShell`：顶栏 + 三栏容器 + 响应式断点切换。
- `Breadcrumb`：章 > 小节 > 知识点（来自 `volume-1.json` 层级）。
- `CourseOutline`（左栏）：渲染章/小节/知识点树 + 状态徽标，处理选中态。

### 5.2 知识点学习区（中栏）
- `StepIndicator`：展示设计文档第 4 节十步闭环的当前步。
- `LecturePanel`：渲染 `coreExplanation`、`keyDefinitions`、`keyTheorems`、`proofIdeas`（需 LaTeX 渲染）。
- `DiagramView`：渲染 `diagramIds` 对应的教学图示（任务包 B 的规格），图示为教学材料而非装饰。
- `ExampleCard`：展示例题（`exampleIds`）及拆解。
- `ExerciseCard`：题目（`prompt`）+ 作答输入框；提交触发 `grade`。

### 5.3 AI 老师与反馈（右栏 / 移动抽屉）
- `TutorChat`：承载 `explain` / `ask` 的对话流。
- `HintStepper`：分层提示控件，逐级请求 `hint`，显示 `level / maxLevel`，最后一级才揭示完整思路。
- `GradeResultCard`：渲染 `grade` 输出（verdict、score、feedback、missingKeyPoints）。
- `MasteryBadge`：根据 `mastery` 结果显示掌握度状态。

### 5.4 设置与进度
- `ModelSettingsForm`（P6）：供应商/模型选择 + API Key 输入（本地保存，见 §7）。
- `ProgressOverview`（P7）：各知识点掌握度汇总。

## 6. 题目与掌握度状态可视化

状态必须清晰可辨（设计文档第 9 节）。

知识点掌握度（与 `masteryState` 一一对应）：

| 状态 | 文案 | 视觉建议 |
| --- | --- | --- |
| `not_started` | 未学 | 空心圆 / 中性灰 |
| `emerging` | 初步掌握 | 半填充 / 蓝色 |
| `proficient` | 熟练 | 实心对勾 / 绿色 |
| `weak` | 薄弱 | 警示点 / 琥珀色，提示补练 |

题目作答状态：未作答 / 已提交待批改 / 已批改（correct·partially_correct·incorrect 用不同色阶）/ 使用了第 n 级提示。批改结果与提示层级都应在题卡上留痕，便于复盘。

---

## 7. 模型 / API Key 设置（P6）

依据设计文档第 8 节：

- 字段：供应商（初期 1–2 个）、模型、API Key、可选的 baseURL。
- API Key **优先保存在浏览器本地**（如 `localStorage`），不进入数据库、不随请求日志留存。
- 表单需有「测试连接」与清除按钮；未配置 Key 时，学习区的 AI 功能区显示「请先在设置中配置模型」的引导，而非静默失败。

---

## 8. 视觉原则

- 安静、清晰、学术、温和；像「精美讲义 + 一对一辅导窗口」的结合。
- 不做营销首页风，不做幼稚风；颜色克制，层次靠留白与字重而非强色块。
- 公式必须可读：统一 LaTeX 渲染（MathJax / KaTeX），行间公式与正文有足够间距，可缩放。
- 题目、提示、答案、反馈四类信息层次分明，用区块与色阶区分，不混排。
- 图示是教学材料：与讲义同级编排，配标题与 `teacherNotes`，不当背景装饰。
- 长时间学习友好：中性背景、适中行宽、支持浅/深色（深色为后续增强项）。

> 以上为可执行约束，不接受无法落地的笼统措辞；任何视觉决策都应能映射到具体组件、状态或排版规则。

---

## 9. 第一版裁剪

- 不做账号系统、付费、后台编辑器（设计文档第 2 节）。
- 进度与掌握度可先存浏览器本地，与 API Key 同策略。
- 仅「数列极限」章可完整走闭环；其余章节目录可见但置灰。
